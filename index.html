Built for Modern Mobile Workflows

A collection of cloud-assisted virtualization services designed to break hardware barriers.

Transparent Cloud Execution

Execute imports like import torch normally. cpip handles parameters serialization, dynamic WebSocket routing, and brings results back to Termux seamlessly.

Package Virtualization

Decomposes heavy libraries into content-addressed tar.gz chunks, lazy loading only what you access, dynamic-linking with patchelf.

On-Demand Cross-Compilation

Missing an Android wheel? The backend automatically launches a Docker build farm using Android NDK toolchains to compile and sign wheels on the fly.

Zero-Trust Sandboxing

All cloud executions run in Docker containers with limited capability drops, strict read-only rootfilesystems, and tight custom seccomp profiles.

AI Agent Ready

Exposes cpip tools directly to LLM agents. Features ModelRouter to offload calculations depending on local device memory capabilities.

Cloud-Proxied Browsers

Automate scraping or QA with preconfigured Playwright environments in the cloud. Screenshot and retrieve pages natively from Termux.

Quick Start Guide

Set up the client in Termux or host your own backend server on bare-metal or Docker.

1

Install Python and Git inside Termux

pkg update && pkg install python git
2

Clone the cpip repository and install

git clone https://github.com/yashab-cyber/cpip.git
cd cpip
pip install -e .[client]
3

Initialize Config and Login

cpip config --init
cpip login
4

Verify Network Connection

cpip doctor
1

Clone repository on target server

git clone https://github.com/yashab-cyber/cpip.git
cd cpip
2

Create environment configuration .env

JWT_SECRET=your_super_secret_key_here
CPIP_DEBUG=false
3

Launch Docker Compose cluster

make docker-up
4

Point Termux Client to server IP

cpip config --api-url http://your-server-ip:8000
1

Install Ubuntu/Debian native dependencies

sudo apt-get update
sudo apt-get install -y python3 python3-pip python3-venv git build-essential redis-server
2

Create virtual environment & Install Server

git clone https://github.com/yashab-cyber/cpip.git
cd cpip
python3 -m venv venv
source venv/bin/activate
pip install -e .[server]
3

Configure server variables and Start Monolith

export CPIP_HOST=0.0.0.0
export CPIP_PORT=8000
export CPIP_DEBUG=true
export DATABASE_URL=sqlite+aiosqlite:///./cpip.db

uvicorn server.app:app --host 0.0.0.0 --port 8000 --workers 4

Command Line & API Usage

Interact with the CLI, daemon background sync, and remote agent capabilities.

CLI Operations

Install packages with Android wheels:
cpip install requests pandas
Force remote cloud execution for torch:
cpip install --cloud torch
Manage the WebSocket sync background daemon:
cpip daemon start cpip daemon status cpip daemon stop
Check system statistics & connection health:
cpip doctor cpip runtime

Python API Integration

agent_example.py 
# Transparently offload browser automation to cloud
from agent.browser import browser_agent
import asyncio

async def main():
    # Playwright runs inside sandboxed cloud container
    result = await browser_agent.navigate("https://github.com")
    print(result["html"][:100])

asyncio.run(main())
